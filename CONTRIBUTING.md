# Contributing to Análisis de Datos

¡Gracias por tu interés en contribuir a este proyecto! 🎉

## Cómo contribuir

1. Haz un fork del repositorio.
2. Crea una rama para tu cambio (`git checkout -b feature/mi-cambio`).
3. Realiza tus cambios y haz commit (`git commit -m 'Agrega mi cambio'`).
4. Sube tu rama (`git push origin feature/mi-cambio`).
5. Abre un Pull Request describiendo los cambios realizados.

## Estándares de código

- Los notebooks deben ejecutarse de principio a fin sin errores.
- Documenta los pasos de análisis con celdas Markdown.
- Usa nombres descriptivos para variables y funciones.

## Reportar errores

Si encuentras un error, abre un [Issue](https://github.com/ea00d009/analisisdedatos/issues/new) describiendo el problema.
