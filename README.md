# Introducción al Análisis de Datos 📊

Bienvenido al repositorio del proyecto **Introducción al Análisis de Datos**.

## 📌 Descripción
Este proyecto contiene cuadernos interactivos y análisis de datos desarrollados en Python utilizando Jupyter Notebooks.

## 🚀 Contenido del Repositorio
- `Fabricio_Alvarez_TP_Final.ipynb`: Trabajo Práctico Final de Análisis de Datos, incluyendo limpieza de datos, visualización y análisis estadístico exploratorio.

## 📊 Estructura del Análisis
1. **Carga y Limpieza de Datos**: Preprocesamiento de datasets.
2. **Análisis Exploratorio (EDA)**: Gráficos explicativos e histogramas de distribución.
3. **Conclusiones**: Hallazgos clave y resumen de resultados.

## 🛠️ Requisitos e Instalación
Para ejecutar los notebooks localmente:
```bash
pip install pandas numpy matplotlib seaborn jupyter
jupyter notebook
```
